# LazyReading

在状态栏里按字节翻页看 txt。点状态栏上的文字，就是下一页。

## 第一次使用

1. 按 **Alt+`** 选择一个 txt。也可以点状态栏里的「选择文本」，或按 `Ctrl+Shift+P` 搜索「阅读设置: 选择文本」。
2. 选好后，左下角状态栏会显示文件名、字节范围和这一页的文字。例如：`小说.txt  1-60/12000  正文……`
3. 关掉 VS Code 再打开，还会回到这个文件上次读到的位置。

再选别的 txt 时，文件框会打开上次用过的文件夹。每个 txt 各自记住读到哪一个字节，换回来不会从头开始。这些位置记在本机，不跟着某一个文件夹走。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| Alt+` | 选择 txt |
| Alt+1 | 上一页 |
| Alt+2 | 隐藏或显示状态栏里的文本 |
| Alt+3 | 下一页 |
| Alt+4 | 跳转到章节 |
| Alt+5 | 转至某一行，或某一个字节 |

按键可以在「键盘快捷方式」里搜索 `lazier` 后自行修改。

## 翻页

默认一页最多 60 字节。打开设置，搜索「阅读设置」，可以改这三项：

- **要翻页阅读的 txt**：当前文件。也可以直接写成绝对路径。
- **每页最多读取的字节数**：1 到 4096。按完整字符换页，一个汉字不会被切成两页。
- **回到第一页**：读到这个文件的最后一页后，再按下一页会回到开头。关掉后就停在最后一页。

隐藏的是状态栏里的这段文字，不是整个状态栏。再按一次 Alt+2 会显示回来。

## 章节和转至

**Alt+4** 列出识别到的章节，点一项就翻到那一行。能识别的是单独占一行的标题，例如：

- `第一章`
- `第一章 开始`
- `第一章：开始`
- `#CH 序章 #CH`

`第一章他走了` 这种章名贴着正文的不算章节。一个都没识别到时，会提示「没有识别到章节」。

**Alt+5** 打开「转至...」。选「行」按行号跳，选「偏移量」按字节位置跳。字节从 1 开始，和状态栏上的数字一致。窗口里也可以按 Alt+L 切换行、Alt+O 切换偏移量、Alt+G 或回车定位、Esc 取消。
